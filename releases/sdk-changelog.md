# SDK changelog

## 0.1.0 — documented release candidate

Initial documented public SDK:

- ESM exports for portable authoring, Node worker execution and browser module
  workers, with public TypeScript declarations.
- Templates backed by the installed `evidence-review/1` and
  `assess-value-of-learning/1` reasoning patterns.
- Canonical source parsing, template/app validation and packing, frozen package
  verification and bound case snapshots.
- Assessment-only execution and complete run/report artifacts for both patterns.
- Prepared report datasets, selection contexts, navigation, connection diagrams,
  payoff bars and qualified timelines.
- Explicit archived-output comparison and prior-input recomputation.
- Structured diagnostics, bounded execution, cancellation and output limits.

Requires Node 22.12.0+ for Node execution. The SDK has no external runtime
dependencies and performs no application persistence. Package publication status
is described in [release information](README.md).
